# 共享训练轨迹的检查点选择协议（精简备选）

<!-- 仅为方法准备稿，不包含新结果或完成声明。C1–C8与 compact_en.tex 逐段对应；不替换已验收的原片段。 -->

<!-- C1：范围与既往接触 -->
本协议规定 360 条主要训练轨迹，即每个语料 24 个 draw、每个 draw 五个外层折，另加 24 次 CREMA-D 配对对照拟合。检查点规则共享训练轨迹和说话人独立外测集。CREMA-D、SUBESCO、RAVDESS 分别保留原生六类、七类、八类任务，以及 91、20、24 名说话人〔cremad；subesco；ravdess〕。这些语料已有研究接触历史。协议采用执行前的私有源码与计划冻结，不是公开预注册。新 draw 不构成此前完全未接触的数据。

<!-- C2：说话人和文本分配 -->
每个 draw 按记录的性别分层，以元数据哈希把说话人分为五个外层折；每人恰好属于一个外测折。在该折之外选择互不重叠的开发组 A、B，各组性别平衡，在选定文本上完整覆盖原生类别。所有 query 组共享文本，且这些文本与训练文本不相交（见下表）；未选中的说话人不使用。冻结的代表录音规则为 CREMA-D 优先 MD、否则 XX，SUBESCO 使用 T1，RAVDESS 使用正常强度 R1，不用其他 take 补位。外测 query 保留可用代表录音，同时要求每名外测说话人均有全部原生类别。开发容量不足触发元数据检查失败，不能依据模型结果重新抽样。

| 语料 | 类数 | A/B 人数 | 外测人数 | 训练/query 文本数 | 每次训练录音数 | A、B 各自 query 录音数 |
|---|---:|---:|---:|---:|---:|---:|
| CREMA-D | 6 | 24/24 | 17/19 | 4/2 | 576 | 288 |
| SUBESCO | 7 | 8/8 | 4 | 4/2 | 224 | 112 |
| RAVDESS | 8 | 8/8 | 4/6 | 1/1 | 64 | 64 |

表：每个 context 的预定配置。A、B 等大且各自性别平衡；数量指不同的说话人或录音。训练/query 列表示文本数，Query 表示 A、B 每组的录音数。外测 query 使用 CREMA-D 的可用代表录音、SUBESCO 的 56 条录音，或 RAVDESS 的 32/48 条录音。斜线分隔的外测数量表示不同折可能具有的规模。

<!-- C3：固定优化 -->
主要轨迹使用 A 组训练。WavLM base-plus〔wavlm〕在最后一层特征的时间均值之上接原生类别数的线性分类头，只训练最高四个 Transformer 层与分类头。固定配置沿用此前研究中的 cfg3：AdamW，编码器/分类头学习率为 5×10^-5 / 10^-3，weight decay 为 0.01，batch size 为 16，使用不加类别权重的交叉熵。训练完整遍历训练集 15 轮，不提前停止、不搜索超参数。训练使用 FP16 autocast 与 FP32 参数；评估使用 FP32。单声道 16 kHz 音频按 30 dB 阈值修剪静音；训练使用三秒裁剪或补零，评估取前至多十秒。

<!-- C4：选择规则和 padding 上下文 -->
A query 提供已见说话人验证，B query 提供未见说话人验证。全部 15 轮记录 A、B、outer 的 logits。四条规则分别在 A 或 B 上最小化平均交叉熵，或最大化 UAR；精确并列取最早轮次，以有理数召回计算保留 UAR 的精确并列。UAR 是整个 query 组全部原生类别的宏平均召回率，不是逐说话人 UAR 的平均。每组独立按固定排序组成 batch size 为 16 的批次，跨轮次与配对模型保持相同。外测音频不能参与验证批次的补零。池化没有长度 mask：这里固定了 padding 上下文，但 padding 效应仍然存在。

<!-- C5：估计量 -->
令 T(g,q) 为验证组 g（已见 s、未见 u）按准则 q 选定轮次的外测 UAR，单位为百分比。每个 context 的对比为：

`δ_q = T(s,q) - T(u,q)，q∈{CE,UAR}`

`J = δCE - δUAR`

这些是单位为百分点（pp）的外测 UAR 差异，不是损失差，也不是验证乐观偏差（V-T）的差异。它们比较选择规则，不识别某个唯一的说话人机制。四条规则复用一条轨迹，不需要四次训练。

<!-- C6：预定推断 -->
每个语料内，先等权平均一个 draw 的五折效应，再以 24 个完整 draw 的效应进行双侧单样本 t 推断（df=23）。六项检验族为三个语料各自的 (δCE,J)，在 0.05 水平使用 Holm 控制，并给出逐项 95% t 区间。零样本方差导致未定义的检验保留 NA，仍占据其检验族位置。绝对 UAR 和 δUAR 仅作描述。1 pp 是实际幅度参照，不是等效界值；本研究不做等效性检验。推断条件于有限语料与训练程序；折、录音、重复出现的人物和规则不是额外独立重复。各语料原生任务不同，不能据此合并作总体推断或声称语言效应。

<!-- C7：配对整组对照 -->
CREMA-D 的 fold 0 每个 draw 增加一个 B 训练的模型，与 A 共享初始权重、匹配的随机日程以及性别/文本/类别训练槽预算。每个性别内，槽还匹配说话人顺位、take 和强度。B 完整训练 15 轮，只记录末轮 query，不选择检查点。令 Q_A、Q_B 为相应整个 query 组的 UAR，单位为百分比：

`E = 0.5 × {[Q_A(M_A15)-Q_A(M_B15)] + [Q_B(M_B15)-Q_B(M_A15)]}`

24 对结果及其均值仅作描述。这里替换的是整个训练人群，不是单个说话人；相同 query 也用于选择主要 A 轨迹的检查点。

<!-- C8：封存与诊断 -->
四次技术 pilot 不计入 384 次拟合。评分要求完成源码、产物、检查点与 ledger 核验。预定描述保留选中轮次的分布及一致性、全部 15 轮的外测曲线、末轮 UAR、8–10 轮相对 14–15 轮的均值 UAR 差，以及相对各轨迹最高外测 UAR 的差距。该 oracle 不选择保留的检查点，也不延长训练。完整处理、随机化与核验细节随冻结协议提供。
