# 共享训练轨迹的检查点选择协议

<!-- 仅为方法准备稿，不包含新结果或完成声明。M1–M8与英文段落逐点对应。 -->

<!-- M1：范围与既往接触 -->
本协议规定 360 条主要训练轨迹，即每个语料 24 个 draw、每个 draw 五个外层折，另加 24 次 CREMA-D 配对对照拟合。它在共同训练轨迹和共同说话人独立外测集上比较检查点选择规则。CREMA-D、SUBESCO、RAVDESS 分别保留原生六类、七类、八类任务，以及 91、20、24 名说话人〔cremad；subesco；ravdess〕。这些语料已有研究接触历史，新 draw 不构成此前完全未接触的数据。本协议采用执行前的私有源码与计划冻结，不是公开预注册。

<!-- M2：说话人、文本与代表录音 -->
每个 draw 按来源记录的性别分层，以仅依赖元数据的哈希把说话人分为五个外层折；每人恰好属于一个外测折。在该折之外选择互不重叠的开发组 A、B，各组女性与男性人数相等，并要求在选定的训练与 query 文本上完整覆盖原生类别。三个 query 组使用相同文本，且这些文本与训练文本不相交（见下表）。未选中的开发说话人不使用。应用冻结的卫生规则后，CREMA-D 优先取 MD、否则取 XX 代表录音；SUBESCO 取 T1；RAVDESS 取正常强度的 R1。预定规则无法提供代表录音时，不用其他 take 补位。外测 query 保留可用代表录音，同时要求每名外测说话人均有全部原生类别的支持。开发数据容量不足应触发元数据检查失败，不能依据模型结果重新抽样。

| 语料 | 类数 | A/B 人数 | 外测人数 | 训练/query 文本数 | 每次训练录音数 | A、B 各自 query 录音数 |
|---|---:|---:|---:|---:|---:|---:|
| CREMA-D | 6 | 24/24 | 17/19 | 4/2 | 576 | 288 |
| SUBESCO | 7 | 8/8 | 4 | 4/2 | 224 | 112 |
| RAVDESS | 8 | 8/8 | 4/6 | 1/1 | 64 | 64 |

表：每个 context 的预定配置。A、B 等大且分别性别平衡；人数或录音数均指不同的人或录音，不是训练更新次数。外测 query 使用 CREMA-D 的实际可用代表录音、SUBESCO 的 56 条录音，或 RAVDESS 的 32/48 条录音。斜线分隔的外测数量表示不同折可能具有的规模。

<!-- M3：固定优化与波形处理 -->
每条主要轨迹只用 A 组录音训练。WavLM base-plus〔wavlm〕在最后一层特征的时间均值之上接原生类别数的线性分类头，只训练最高四个 Transformer 层与分类头。固定配置沿用此前研究中称为 cfg3 的配置：AdamW，编码器/分类头学习率分别为 5×10^-5 / 10^-3，weight decay 为 0.01，batch size 为 16，使用不加类别权重的交叉熵。训练完整遍历训练集 15 轮，不提前停止、不搜索超参数；训练使用 FP16 autocast 与 FP32 参数，评估使用 FP32。音频以单声道 16 kHz 加载，按 30 dB 阈值修剪静音，缓存为 FP16，在组批时转为 FP32。训练使用三秒裁剪，较短录音补零；评估取处理后音频的前至多十秒。

<!-- M4：四规则、并列与固定 padding 上下文 -->
对于 A 训练的模型，A query 是已见说话人的验证集，B query 是未见说话人的验证集。每轮记录 A、B、outer 三组 query 的 logits。四条规则分别在 A 或 B 上最小化平均交叉熵，或最大化无权平均召回率（UAR）；精确并列时取最早轮次。UAR 是整个 query 组全部原生类别的宏平均召回率，不是逐说话人 UAR 的平均。整数/有理数召回计算保留精确并列。每组分别按固定排序组成 batch size 为 16 的批次，跨轮次与配对模型复用。外测录音不会参与验证批次的补零。网络的均值池化没有长度 mask，因此这里只固定 padding 上下文，没有消除 padding 效应。评估保留训练 RNG 状态，每轮训练恢复训练模式。

<!-- M5：估计量 -->
令 T(g,q) 为验证组 g（已见 s 或未见 u）按准则 q∈{CE,UAR} 选定轮次的外测 UAR，单位为百分比。四条规则复用一条已拟合轨迹，不是四次训练。每个 context 的对比为：

`δCE = T(s,CE) - T(u,CE)`

`δUAR = T(s,UAR) - T(u,UAR)`

`J = δCE - δUAR`

这些对比衡量单位为百分点（pp）的外测 UAR 差异，不是交叉熵损失差，也不是验证乐观偏差（V-T）的差异。它们比较算法选择规则，而不识别某个唯一的说话人机制。

<!-- M6：预定推断族与范围 -->
每个语料内，先等权平均一个 draw 的五折对比，再以 24 个完整 draw 的效应进行双侧单样本 t 推断（df=23）。固定六项检验族为三个语料分别检验 (δCE,J)，在 0.05 水平使用 Holm 控制，并给出逐项 95% t 区间。零样本方差导致未定义的检验保留 NA，仍占据其检验族位置。绝对 UAR 与 δUAR 仅作描述。不做 bootstrap 或等效性检验；1 pp 是预定的实际幅度参照，不是等效界值。推断条件于各自的有限语料与训练程序；折、录音、重复出现的人物和选择规则都不是额外独立重复。各语料原生任务不同，因此不合并作总体推断，也不把库间差异解释成语言效应。

<!-- M7：整组角色互换对照 -->
CREMA-D 每个 draw 的预定 fold 0 增加一个 B 训练的模型。配对拟合共享初始权重，并共享按初始化、排序、裁剪、训练分别管理的种子；训练槽按性别、组内说话人顺位、文本、类别、take 与强度匹配。B 完整训练 15 轮，但只在第 15 轮记录 query，不选择检查点。令 Q_A、Q_B 表示相应整个 query 组的 UAR，单位为百分比，描述性对照为：

`E = 0.5 × {[Q_A(M_A15)-Q_A(M_B15)] + [Q_B(M_B15)-Q_B(M_A15)]}`

协议报告 24 个配对值及其均值，不增加推断。这一操作替换的是整个训练人群，不是单个说话人；相同 query 也参与主要 A 轨迹的检查点选择。

<!-- M8：封存与预定诊断 -->
四次独立技术 pilot 不计入 384 次正式矩阵。科学评分要求全部正式单元通过源码、产物、检查点与 ledger 核验。主要轨迹保留全部 15 轮 query logits，以及四规则获胜状态与末轮状态去重后的 checkpoint delta；对照保留末轮状态。磁盘回载要求 logits 的最大绝对差不超过 10^-5。封存后的预定描述包括选中轮次分布及一致性、完整外测曲线、末轮 UAR、8–10 轮相对 14–15 轮的均值 UAR 差，以及所选检查点相对同一轨迹最高外测 UAR 的差距。外测 oracle 不参与保留检查点的选择，也不用于延长训练。
