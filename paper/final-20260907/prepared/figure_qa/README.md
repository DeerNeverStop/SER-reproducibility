# 模拟图表的实际排版验收

本目录保存训练期间完成的 **SYNTHETIC 排版检查**，不含本轮384次正式研究的科学成绩，也不是最终论文。英文主稿和中文全文尚未填入新结果。

- 曲线画布从11×3.3改为6.5×2.75英寸，图例移到图外，总标题分行。所有15轮、每库120条外测轨迹、三角色等权均值和0–100轴保持原算法。
- 实际spconf英文以178mm嵌入后，图中最小字号9.53271pt；中文正文宽487.27559pt，实际中文生成器输出最小9.20546757pt。239个非空图字符与原图逐字一致，旋转纵轴文字也按em字号检查。
- 中文生成器现在接受独立的`![图注](相对路径.pdf)`行，并要求`--figure-manifest`绑定图文件。仅接受清单同目录内、SHA匹配的单页未旋转本地PDF，等比预留真实正文空间，再合并矢量内容；图注随图分页。无图调用不需要清单。
- 实际中文样稿为3页：图及图注同处第2页，参考文献第3页，保留3个书签、页眉页脚和嵌入字体。每次构建另写`输出.pdf.build.json`，记录输入、图位、缩放与输出SHA。

[LAYOUT_CHECKS.json](LAYOUT_CHECKS.json)保存精简的实际检查、输入/输出身份和根任务逐页视觉记录；完整逐字符收据留在其中指向的本地归档。收据是从原JSON选择字段组成的新文件，不冒作原收据字节副本。原始失败记录也保留：最初理论缩放误差阈值过严，英文宽度只差0.03068pt；后改为明确的0.1pt物理宽度容差，9pt字号要求未放宽。

[geometry_qa.py](geometry_qa.py)与实际运行脚本字节相同。其命令入口限定明确标记的模拟输入，检查PDF中原始字体大小乘以**已合成**变换矩阵的纵向em轴长度，避免旋转文字边界框高度或重复乘缩放造成误判。它不批准视觉质量；逐页彩色、灰度及页眉区域查看由根任务实际完成。

正式结果进入两版后，必须重新检查新图、图注、字体、文字、整篇页数及全部新页面。此处的中文空白几何页、实际中文样稿和完整最终论文分别属于不同验收范围，不能相互替代。英文第5页仍仅参考文献，图表和披露须留在前4页。
