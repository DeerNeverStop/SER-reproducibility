## 1. C 的定义与池内结果：部分接受，不能混淆目标

冻结 [执行方案](../speaker_coverage/EXECUTION_PLAN.md) 和 [选择实现](../speaker_coverage/plan.py) 区分了两个目标：

- **R** 贪心降低候选池的平均最近邻距离，再作同 sex 一对一交换改进：`mean_x min_s d(x,s)`。
- **C** 每步选取到当前集合的最近距离最大的、且性别配额尚未满的候选人，是配额约束 farthest-first，几何方向为最坏最近邻距离 `max_x min_s d(x,s)`。C 没有优化平均 NN1/NN3，也没有声明全局最优。配额和 cosine distance 不允许直接套用无约束 metric k-center 的标准保证。

故“C 平均 NN1 比 R 差，所以 C 不是覆盖算法／在自身平均目标上失败”不成立。**但 Claude 指出本次 R 的最大 NN1 也通常更低，数值确实成立，应该披露。**

| 池内指标，含选中人，90 个配对视图等权 | U | R | C |
|---|---:|---:|---:|
| 平均 NN1 | 0.356447 | 0.321498 | 0.348126 |
| 最大 NN1 | 0.770476 | 0.657004 | 0.696548 |
| 最近三人距离的平均值 | 0.558998 | 0.555323 | 0.586444 |

C 的最大 NN1 比 U 在 90/90 个视图中低，整体均值减少约 **9.60%**；R 在 87/90 个视图中又低于 C。C 的平均 NN1 没有一次低于 R，平均 NN3 没有一次低于 U。可保留具体策略名称“12F/12M 配额下 ECAPA farthest-first”，避免把这一启发式等同于所有覆盖策略。R 被列为次要比较、C−U 被列为主比较，是冻结时的选择；不能因结果再交换主终点并装作预先指定。

## 2. 新补的真实 outer-test 几何

每个冻结单元从实际 `test` 路径取外测人，从实际 `fit` 路径取选中的 24 人。训练人参考仍用当初选择所用的八个允许训练文本的 neutral 代表录音：逐条单位化、求均值、再单位化；它是**选人参考轮廓**，不意味着每个训练人实际拟合了八句（实际为四句）。距离为 cosine distance，越小越近。

两种事后口径均在计算前写入本复核代码，并全部保留：

1. **同八文本完整参考**：外测人也使用相同八个训练文本的 neutral 代表，以减少参考文本与条数差异。缺任何一条就将该 person×rotation 标为不完整，对三策略统一不计；不补录、不替换人、不悄悄减少参考条数。
2. **真实 query 参考**：使用冻结 `test` 内实际存在的 neutral query 录音，通常两条，少数一条。覆盖所有测试视图，但与训练人的八条参考在文本和条数上不同，是辅助观察，不能当纯身份距离实验。

| 外测指标，每视图等权 | U | R | C |
|---|---:|---:|---:|
| 同八文本：平均 NN1 | 0.584055 | 0.574814 | 0.602815 |
| 同八文本：最大 NN1 | 0.751638 | 0.746790 | 0.747591 |
| 同八文本：平均 NN3 | 0.645780 | 0.640656 | 0.667936 |
| 实际 query：平均 NN1 | 0.644565 | 0.637755 | 0.659378 |
| 实际 query：最大 NN1 | 0.791183 | 0.791957 | 0.792155 |
| 实际 query：平均 NN3 | 0.699221 | 0.696079 | 0.717844 |

这里 NN3 是到最近三名训练人的距离平均，不是第三近距离；逐人表还单独保留第三近距离。最大 NN1 是每个外测视图内逐人 NN1 的最大值，表中再平均这些最大值。

**结果不支持“池内改善意味着外测总体变近”。** 同八文本口径下，C 相对 U 的平均 NN1/NN3 分别增加约 **3.21%/3.43%**，最大 NN1 只减少约 **0.54%**；实际 query 口径下，平均 NN1/NN3 同样更大，最大值近乎不变。可修正为：“C 改善了候选池的最坏最近邻距离，但外测人的平均近邻距离没有改善；本轮也未检出主 SER 收益。”这仍不能推出几何变化导致 SER 变化或解释其全部机制。

参考完整性：总计 `91人×6句对=546` 个不同测试 person×rotation。同八文本口径有 **23 个不完整**，涉及 1002、1006、1008、1009、1019、1076 六人；跨三 draw、三策略形成 207 条明确 omission 记录。其余 523 个不同 person×rotation 可用，各策略 1,569 条视图记录；91 人都至少有一个可用 rotation，但有效 rotation 不等。实际 query 口径保留全部 546 个组合，其中六个只有一条 neutral；各策略共1,638条记录。完整缺失清单在 JSON。

本次不使用 SER 预测或误差来定义几何，但**使用了既有 neutral 标签筛选参考录音**，不能严格写成完全不看标签的无监督处理。所有测试侧距离仅供探索报告，禁止据此改选集合、删人、调指标或重新挑选主终点。

## 3. 聚合与重复的层级

上表为 `5 fold × 6 rotation × 3 draw` 的 **90 个配对视图**，不是90组独立实验。R/C 选人及参考在三 draw 中不变，只有30个不同的几何上下文；U 的集合随 draw 变化。外测说话人反复出现，训练集合也重叠，不能按视图数声称有效样本量90或270。

JSON另报先对每人平均 rotation/draw，再91人等权的口径，避免把不同折人数混同为同一估计量。例如实际 query 的逐人等权平均 NN1 为 U **0.644796**、R **0.638070**、C **0.659377**；方向与上表相同。同八文本的逐人平均有不等参考完整性，应连同缺失结构解释。本几何复核不制造显著性检验或因果中介结论。

三策略等权平均 **+1.031530 pp**，Claude 的“约1.032 pp”成立。本次区间使用 NumPy PCG64 seed=20260906、10,000次同一组91人配对重抽；Claude 给出的区间略有差别，未提供相同随机数与方法合同就不能要求逐位一致。上述区间是事后探索、条件于已拟合模型，不是新确认性结果或多重校正结论。

两个 checkpoint 来自同一条完整100轮训练轨迹，差别在选择规则；“末轮平均更高”不能单凭聚合相关性证明某一种早停机制，更不能承诺以后任务都选末轮。冻结主终点仍须保留，新诊断应另列。

## 5. Holm 和替代区间：不接受精确推断式措辞

为复核 Claude 的算术，本代码演示将 percentile CI 的宽度除以 `2×1.959964` 当作正态 SE，再反推 p。最小代理 p 为 **0.03175064**，将全部12行当一个族作 Holm 得 **0.38100768**，确实约等于 Claude 的0.0318/0.38。

**但这不是有效精确 p 的复算。** Percentile bootstrap 区间并不唯一确定标准误、抽样分布或零假设 p；区间还可能非对称。Holm 本身可以容许依赖，但需要有效的边际 p，而不是从任意 CI 反推的代理。12行还含重复的 Ridge best/last，同时混有一个冻结主终点与若干敏感性对比。建议措辞是：“两条FT末轮结果仅有名义区间证据；本次没有预定并验证的多重校正确认性结论。正态反推的敏感性演示也未通过12项Holm。”不要写成已经实施严格 Holm、得到精确调整 p=0.38。

折级 t 区间算得 **[−1.019035, 0.761454]**，但其中心是等折均值 **−0.128790**，不是原等人主估计 **−0.109150**。draw级 t 区间 **[−1.823241, 1.604940]** 的算术也成立。**更宽不自动等于更诚实**：五折的训练集合重叠，三个draw复用同一批测试人，R/C 的成员仍固定；折独立或draw独立的总体抽样解释并未因此成立。原区间应继续明确“条件于这些已拟合模型”的范围；替代区间可作描述性敏感性分析，不宜升格为解决依赖的正确答案。由事后SE构造的MDE，也不能当作排除了该阈值以内效应或支持零效应的证据。
