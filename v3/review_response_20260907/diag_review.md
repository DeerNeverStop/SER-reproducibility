# DIAG 两项断言的独立复核

日期：2026-09-07。对象为 [Claude PR16 评价](../CLAUDE_EXPERIMENT_REVIEW_20260907.md)的 DIAG 总评及 B4。只复用已提交 CSV；没有读取原始 logits、重新推理、训练，或为真实结果新增 p 值、置信区间。可复算结果见 [JSON](diag_decomposition.json)、[480 行选择明细](diag_decomposition_cells.csv)与[独立脚本](diag_decompose.py)。

**结论：全局选频乘全局配置均值不是本次选后报告差的严格恒等式；2.30 pp 是可重建的特殊假设基线，但不能据“观察更低”推出没有信息。** 同时，Claude 对“该诊断没有独立新训练证据”和“非负复用量不能单独证明机制”的提醒成立。这些代数修正不把 DIAG 升格为确认性发现，也不证明纯身份机制。

## 1. 实际选择加权与全局边际乘积

令 j 为一个 draw×fold×方向，共 24×5×2＝240 个等权 cell；c 为四个配置之一。I_jc 表示该方向是否选中 c，D_jc 为 c 在该方向**报告半**的 seen UAR−unseen UAR。全部均值和协方差均按这 240 个 cell 的有限总体均值定义，协方差分母为 240。

真正恒等式是：

`mean_j sum_c I_jc D_jc = sum_c mean_j(I_jc) mean_j(D_jc) + sum_c Cov_j(I_jc,D_jc)`

也可写成选择概率乘以**该配置被选中 cell 的条件均值**。条件均值不能直接换成该配置在全部 cell 的均值。选择根据同一面板另一半上的性能决定；没有依据令选择指示与报告曝光差独立。这里的 covariance 是精确算术剩余，不是新统计检验或因果效应。

| 规则 | 按实际 cell 选择加权 (pp) | 全局选频×全局配置均值 (pp) | 被省略的协方差和 (pp) |
|---|---:|---:|---:|
| seen | 2.9369212963 | 2.9349440586 | +0.0019772377 |
| unseen | 2.9918981481 | 2.9421296296 | +0.0497685185 |

Claude 的 2.935／2.942 是上述乘积的合理三位小数近似；它们**不是**报告的 2.937／2.992。尤其 unseen 的差为 0.0497685 pp，不能归为显示舍入。seen 的小净差也不代表所有配置项为零，而是正负项抵消。

|---|---:|---:|---:|---:|---:|
| 0 | 2.4681712963 | 42 | +0.0281394676 | 43 | −0.0110797647 |
| 1 | 2.6649305556 | 31 | −0.0375072338 | 28 | −0.0070891204 |
| 2 | 3.2320601852 | 112 | −0.0181327160 | 116 | +0.1710551698 |
| 3 | 2.8385416667 | 55 | +0.0294777199 | 53 | −0.1031177662 |

脚本从等类支持的 144 条半组 CSV 恢复整数正确数，以 Fraction 计算选择和差分；逐项核对 480 个 episode，并确认全部 960 个旧末轮完整验证值恰等于两半平均。完整固定 config 3 差是 2.8385416667 pp；选后报告差是同一数据上、随选择程序改变的条件描述，不能称与它数值上严格同一个量，也不构成独立重复。

建议最小改写：**“选后报告曝光差是各配置在其被选中面板上的报告差的加权平均，数值与固定配置描述接近；它复用相同训练和录音，提供选择程序下的描述，不是新的独立验证。”** 若引用全局频率近似，应同时保留协方差项及其实际大小。

## 2. 2.233 与 2.30：可重建的假设，不能用作信息量判决

可从配置在 A/B 半的分数差 d_pc 构造一种与审阅数字一致的方差估计：

`sigma_e² = sum_p,c [d_pc−mean_c(d_pc)]² / [2×120×(4−1)]`

两组分别得到 seen 2.316478、unseen 2.146047 pp，等权合并方差后开方为 **2.232889 pp**，与 2.233 一致到其报告精度。这只是重建了一种匹配的 ANOVA 型估计；Claude 未附原脚本，不能声称复现了其精确残差定义或那 1000 次模拟。

在每个配置真实均值相同、两个半组配置特异误差独立同方差高斯的模型中，双向平均复用量的期望为 `sigma_e × E[max(Z0,Z1,Z2,Z3)]`，约 **2.29848 pp**。这支持 2.30 的数量级，而不是证明该模型适配实际数据。144 条录音来自 12 人及重复文本，不能仅由 n＝144 推出独立同分布误差；配置共用拟合、人物和录音，其误差相关结构也未由该标量确定。

非负性本身来自两方向 argmax：若 cA、cB 分别在 A、B 最优，则双向平均复用量为 `[(A_cA−A_cB)+(B_cB−B_cA)]/2 >= 0`。这个构造性质不证明复用量没有其他描述信息，也不等价于其大小必须达到独立纯噪声的均值。

为检查“低于 2.30＝无信息”是否逻辑成立，脚本使用显式玩具模型：

`A_pc = mu_c + tau Z_pc + sigma_e epsilon_pcA`
`B_pc = mu_c + tau Z_pc + sigma_e epsilon_pcB`

Z 是跨半组共同的、面板特异的配置质量；epsilon 是各半独立噪声。tau 网格只取 0、0.5、1、2 倍 sigma_e，未调参使其匹配观察。所有配置的**全局**真实均值仍相同，tau>0 却意味着当前面板有可迁移到报告半的配置质量信号。d=A−B 中共享项抵消，因此这个模型保持相同的半差残差尺度。

| tau/sigma_e | 解析期望复用量 (pp) | 1000 次模拟均值 (pp) |
|---|---:|---:|
| 0：无共享配置信号 | 2.298481 | 2.297043 |
| 0.5 | 2.055824 | 2.061933 |
| 1 | 1.625272 | 1.631442 |
| 2 | 1.027912 | 1.020768 |

解析期望为 `sigma_e×E[max4 Z]/sqrt(1+(tau/sigma_e)²)`。可跨半泛化的配置信号越强，选择后复用差反而可以越小。因此，实际 seen **1.536458**／unseen **1.394676** pp 低于 2.30，既不能推出“信息为零”，也不能单凭这张敏感性表反向证明真实信号存在。

另以旧完整验证表的四配置全局均值作为 mu 的事后代入，只保留独立误差时，模拟均值约 seen **1.777584**、unseen **1.957124** pp。它同样只是展示假设变化的影响；全局均值也是从这些数据估计，不能称为已拟合并验证的零假设。

全部模拟使用 PCG64、基础种子 **2026090716**，每情景独立 SeedSequence，1000 次，每次 120 个假设独立面板。JSON 保留模拟分布分位数；它们不是实际研究的区间，也未校准真实人物、折和 draw 的重复依赖。不能把模拟区间与实际观察比较后另作未预定显著性判断。原数据的配置半差相关矩阵仅作描述：共同半组难度也会造成相关，并可能在 argmax 中抵消，相关性本身不是对该方差估计的单独否证。
