# 对 Claude 的 DUAL 与新增角色互换建议的独立复核

2026-09-07。已读取 `v3/CLAUDE_EXPERIMENT_REVIEW_20260907.md`，并复核原冻结计划、480 个预测档案的 last 验证输出、固定 score CSV/JSON。未读取 checkpoint 权重、未训练、未运行 GPU、未改原报告或冻结主终点。新增区间和检验均是**看到 Claude 评价后的事后探索、未经多重比较校正**；原预定主检验保持原有身份。

## 结论先行

建议**撤回把新增 240 次拟合作为默认下一步的安排，暂不为它租卡**，保留为有明确增量理由时再执行的方案。Claude 正确指出：原 DUAL 并非始终固定两组人，随机化已让全部人物反复交换角色；我们此前把“人物静态难度”讲得过于像一个完全未被处理的解释。已有数据上的明确固定效应规格也没有消除平均正差。

但不接受“FE 已证明单人因果效应”“两策略一样好”“未见验证基本无偏”“应事后替换原主终点”等升级。新的成对角色互换确有同一文本/报告录音/初始化框架内比较的作用，却不应再被包装成首次获得角色轮换识别；它仍同时替换整个拟合人群。当前先整理已有证据比追加训练更合适。

## 角色随机化：关键批评成立

从固定 cfg3 的 120 个 draw/fold 面板恢复 5,760 个 person×context 验证观测：

| 核查项 | 实际复算 |
|---|---:|
| 两种验证角色均出现过的人数 | **91/91** |
| seen 次数 / (seen+unseen 次数)，等人均值 | 0.500354 |
| 上述比例范围 | 0.285714–0.628571 |
| 同一 fold、不同 draws 的拟合人交集平均 | 6.513043 / 24 |
| 交集比较数量 | 1,380 |

比例分母不包括 outer 或未选中的 eligible context；不能写成人一半录音用于训练。结果复现 Claude 的角色覆盖与重合数字。

角色随机化会在期望上平衡静态人物难度。有限语料仍可出现不平衡，故用人物固定效应作事后敏感性检查合理；但“原来两组人本身难度不同”应改述为“有限随机化残差，以及人物×文本/模型/曝光交互、整个训练人群随角色变化”，不能继续把原研究说成两组固定人物的比较。

## 固定效应：方向支持，Claude 的具体点/区间尚未复现

先按请求复核固定 cfg3：每位报告人每个 context 恰有 12 条（两句×六类），每类支持 2；逐人 UAR可由正确数/12精确计算。人物和 context 单位没有乘上配置数。

| 明确规格 | 未调整 pp | 角色系数 pp |
|---|---:|---:|
| cfg3，逐 person/context 等权；人物 + joint(draw,fold) FE | 2.838542 | **2.870941** |
| cfg3，人物 + additive draw + fold FE（仅点值诊断） | 同上 | 2.871211 |
| cfg3，只有人物 FE（仅点值诊断） | 同上 | 2.880116 |
| 四个配置 last UAR 先在人/context 内平均，再做人物 + joint context FE | **2.800926** | **2.899325** |

最后一行是唯一有根据的追加重建：Claude 的 2.801 明显对应四配置固定末轮差的均值，而非 cfg3 的 2.839；这部分现已复现。但同一自然规格下 FE 为 2.899325，仍不是其 2.967。没有继续遍历权重或模型去寻找匹配值。另 cfg3 的“先对每个人分别平均两角色再做等人差”是 2.715726，说明权重定义确实重要，不能混用。

对第一行，我们另明确计算了 **24 整 draw 聚类的 CR1 sandwich，t(23)**：SE 0.319255，95% 区间 **[2.210512, 3.531370]**。这是本次新规定的探索区间，绝不是 Claude [2.395,3.581] 的复现。CR1 修正、设计矩阵和输入哈希均存入脚本/JSON。最后一行没有追加区间或检验。

应请 Claude 提供回归代码、逐行权重、joint/additive FE 处理、聚类或重抽单位、区间公式/种子。现阶段可以说“我们的明确规格支持同向、略增的调整后差异”，不能把 2.967 及其区间标为已独立复现，更不能从显著 FE 系数推出纯声纹机制或单人加入效应。

## 其他关键数字均能复算，但需保留身份

下表除第一行原主结果外，新增区间均属于本次事后 draw-level t 探索；全部先在 draw 内按冻结权重聚合五折。

| 量 | pp | 95% t 区间 |

| cfg3 固定末轮 gap 差 | 2.838542 | [2.102301, 3.574783] |
| 主 θ − cfg3 固定末轮 gap 差 | −0.132541 | [−0.959168, 0.694086] |
| 主选择程序的共同外测差 ΔT | 0.847240 | [0.193096, 1.501383] |
| 固定 cfg3、仅检查点规则不同的 ΔT | 0.732244 | [0.270686, 1.193803] |

| cfg3 末轮 seen 验证−外测 | 3.325577 | [2.549454, 4.101699] |
| cfg3 末轮 unseen 验证−外测 | 0.487035 | [−0.196053, 1.170123] |

四配置仅检查点 ΔT 分别为 0.664212、1.159937、0.786107、0.732244 pp；其事后名义区间均为正，合并值在 21/24 draws 为正。它值得作为**事后探索**报告，而不是因为此前未给描述量加 p 值就判报告错误。四配置共享 draws/面板，不构成四项独立重复确认。

−0.132541 的 p=0.743129 可复现，但该数是两个完整估计差之间的差，不能称两种选择规则各自没有影响，不能认定策略等效，也不能将固定末轮差叫原主差的“全部”。θ 包含不同选中模型各自的验证−共同外测差；固定末轮只有同模型两群验证差。两者相关但不是同一个估计量。

unseen 的固定末轮区间跨零，不等于“基本无偏”；上界仍允许约 1.17 pp 的正差，且没有事前等效界限。主程序 unseen gap 为 2.075562；它与固定末轮 0.487035 的差约 1.588527，同时改变了模型与所报告验证分数，不能全部命名为赢家诅咒。

## “第 8–10 轮达峰”能复现分箱数，不能复现学习曲线

四配置 best_seen 的平均所选轮次 **9.639583**，best_unseen **8.656250**，相同轮次 **293/480 = 61.041667%**，与 Claude 一致。但旧引擎只为 `best_seen`、`best_unseen`、`last` 对应的去重 epoch 保存外测预测（`inner_validation/engine.py:165–187`），没有完整 15 轮的逐轨迹测试曲线。

用 `(unit_id, checkpoint_epoch)` 去重后，确实重现其两段均值：

| 被保存/选中的 epoch 分箱 | 状态数 | 不同轨迹数 | 外测 UAR |
|---|---:|---:|---:|
| 8–10 | 158 | 146 | 54.081366% |
| 14–15 | 525 | 480 | 52.537586% |

这是**不同轨迹、配置、面板的选择后截面**；后者还包含每条轨迹必存的第15轮，前者只包含恰好被验证选中的中期状态。若不去重，均值又变为 54.018834 与 53.004184。不能将它写成同一模型测试性能在 8–10 轮达峰、随后下降，更不能据此证明“选更晚所以更好”的机制。

固定配置的 ΔT 对比确实只改变被选取的 checkpoint，故可以报告当前 CE 检查点规则对外测的差异。训练全程15轮没有提前停止，应称“检查点选择差异”，不能误称节省训练的早停实验。其泛化机制及完整峰值曲线本轮未识别，也不建议为补这条曲线临时追加 GPU 推理。

## 对命名、原主终点和下一步的处理

采纳更精确命名：**“不同验证说话人曝光下，所选模型的验证−SI 外测差异”**。明确它不是仅由选模导致的偏差，并紧接着给 cfg3 固定末轮对照。不能因看到对照较大，就把原冻结次要终点提升为新的预定主终点；若之后改写论文叙事，应完整保留研究前后身份。

默认撤回新增240的理由是**已有随机角色覆盖和零GPU复核已能处理相当部分静态人物难度疑问，继续投入的边际价值降低**，不是“FE已证明全部机制”。若将来仍开展，必须把目标改成同一报告录音/文本框架内的成对训练人群替换，并说明如何处理旧推理padding和耦合随机数；承认这是更严格的框架控制/精度检查，不是首次引入角色随机化，也不是逐人因果。
