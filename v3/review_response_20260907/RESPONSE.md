## 1. 用人话说，这次改了什么

第一，原实验已经让同一个人多次轮流扮演“训练见过”和“训练未见”的角色。此前我把“两组人本来就不一样”当成需要再训练 240 次的主要理由，低估了已有随机化。现在确认 **91/91 人都经历过两种角色**，控制人物固定差异后，约 2.8–2.9 个百分点的差距仍在。先用已有数据处理这个问题更合适。

第二，“熟悉声音得分更高”与“用验证集挑模型造成的影响”必须分开讲。即使配置和轮次都不再选择，同一个模型给熟悉人和陌生人打分仍差 **2.839 pp**。原主结果 **2.706 pp** 是两种验证规则选出模型后，各自“验证成绩减共同外测成绩”的差；它包含评分人群和选模程序，不能全部归为选模偏差，也不与固定模型差严格相等。

第三，选人实验的解释需要实质性收窄。我们补算了真正外测人的距离：C 策略让候选池内的最坏最近邻距离下降，但**没有让外测人在平均距离上更接近训练人**。所以不能再用“测试几何已经改善，只是识别率没提高”解释空结果。

第四，检查点选择值得写成下一条待确认的线索。相同配置、相同完整训练轨迹，仅用两类验证人群各自的 CE 挑检查点，共同外测平均相差 **+0.836 pp**。这是事后探索；现有预测没有保存每轮完整测试曲线，不能声称已证明“第 8–10 轮达峰”或某种普遍的早停机制。

## 3. 新复核的数字及边界

全部 91 人均进入过两种验证角色；平均 fit 角色占比为 0.500354，同折不同 draw 的拟合人平均重合 6.513/24。每个 context 内仍是不同两组人，但跨 context 不再是两组固定人。

|---|---:|---|

人物 + joint(draw,fold) 固定效应、逐 person/context 等权的 cfg3 角色系数为 **2.870941**；明确使用 24 个 draw 聚类 CR1、t(23) 得探索区间 [2.210512, 3.531370]。先对四配置末轮取 person/context 内平均，未调整值 **2.800926** 复现 Claude 的 2.801，调整后为 **2.899325**，并非其 2.967。审阅未附回归权重、设计矩阵和区间代码；不能继续挑规格追求匹配数字，也不能由 FE 推出纯声纹记忆或逐人因果效应。

固定末轮 unseen 验证−外测为 **0.487 [−0.196, 1.170]**。区间跨零说明这里没有明确检出偏离，**不能证明“基本无偏”**；与自适应程序 2.076 的差同时改变模型和所报验证成绩，不能全部命名为赢家诅咒。

训练始终完成15轮，所谓 best 是从完整轨迹选检查点，并未提前停训。Claude 的 8–10 轮 54.08%、14–15 轮 52.54% 可重建，但它们来自不同模型被选中或末轮保存的状态，不是逐模型完整学习曲线。细节、代码及输入表见 [DUAL 复核](dual_science_review.md)。

### E2：候选池的覆盖没有转化为外测平均接近

| 参照与指标，cosine distance，越小越近 | 随机 U | 代表性 R | farthest-first C |
|---|---:|---:|---:|
| 候选池：最大 NN1 | 0.770476 | 0.657004 | 0.696548 |
| 同八文本外测参考：平均 NN1 | 0.584055 | 0.574814 | 0.602815 |
| 同八文本外测参考：平均 NN3 | 0.645780 | 0.640656 | 0.667936 |
| 同八文本外测参考：最大 NN1 | 0.751638 | 0.746790 | 0.747591 |

C 相对 U 的池内最大 NN1 下降 **9.60%**，但同八文本外测平均 NN1/NN3 分别增加 **3.21%/3.43%**，最大 NN1 仅下降约 **0.54%**。NN3 指最近三名训练人的距离平均。另用真实 test query 的 neutral 参考时，平均指标方向相同、最坏距离几乎不变。

同八文本参考的 546 个 person×rotation 中有 23 个不完整，涉及六人；三策略统一不计并完整披露。真实 query 口径保留全部组合，参考条数与训练参考不同。参考利用了既有 neutral 标签，不能称完全无标签。外测几何仅用于事后描述，没有据此重选训练人、换主终点或微调距离指标。

原 CNN 主 C−U 仍是 **−0.109 pp [−0.715, 0.509]**，没有检出收益；不能写成证明无效或等效。CNN 末轮减所选最佳检查点的三策略均值 **+1.031530 pp** 可复现，另列探索。Claude 用区间宽度反推正态 p 再作12项 Holm，数值约 0.38，但不是有效精确 p 的复算；更宽的折级/draw级区间也不自动解决训练重叠和测试人物复用。详见 [E2 复核与外测逐人距离](e2_review_notes.md)。

### DIAG：降低论文权重，但纠正过强的否定

两种程序的选后报告差分别为 **2.936921/2.991898 pp**；全局频率乘全局配置均值为 **2.934944/2.942130**，遗漏协方差分别 **0.001977/0.049769 pp**。实际恒等式是逐面板选择加权，或边际乘积加协方差；不是与固定 cfg3 的 2.839 严格同一个估计量。

半组噪声尺度 **2.232889** 和等效配置、独立高斯噪声假设下的期望 **2.298481 pp** 能重建。但加入跨半组共享的配置质量信号，在保持半差噪声尺度不变时，该期望可以降为 **1.625272** 或 **1.027912**。所以“观察到 1.54/1.39 低于2.30，故信息量为零”并不成立；这些敏感性模拟也不反向证明真实数据有信号。

DIAG 仍只适合做方法说明或附录：它复用了同一批训练和录音，双向 argmax 的非负复用量有构造性质，不是第三次独立发现。保留全量描述结果，不追加一批事后显著性来挽救结论。详见 [精确分解与噪声模型边界](diag_review.md)。

## 4. 论文定位与后续实验

已补入 Ibrahim 等人的直接先例：[Scientific Reports 原文](https://www.nature.com/articles/s41598-026-58836-w?error=cookies_not_supported)与[表6](https://www.nature.com/articles/s41598-026-58836-w/tables/6?error=cookies_not_supported)。其 audio-only 分支已经比较随机与人物独立评估，不能再主张首次发现 SD/SI 差距；其表中 accuracy 也不能和本项目 UAR 直接相减。具体增量只能围绕共同候选训练、受控内层验证和明确报告估计量提出，尚不保证足够新颖。见 [相关工作修订](../validation_reporting/RESEARCH_DIRECTION.md)。

当前审阅稿入口为 [paper/submission-20260906](../../paper/README.md)。恢复的是原有完整交付快照，未将这三项新实验塞入正文，也不表示已投稿或发表；不同实验的估计量、指标权重和推断单位不能因数值接近而合并。

后续安排按增量价值排序：

1. **已完成：**角色分配复查、人物 FE 敏感性、检查点选择对比、外测几何、DIAG 精确分解、文献与稿件入口修订。只消耗本机 CPU。
2. **本轮形成的下一项确认候选：**验证检查点规则的外测差是否能在预先固定的独立实验中复现。固定候选训练、最大训练预算和配对规则，明确是比较验证人群还是 CE/UAR 选择目标；二者不能一次混改。先指定一个主对比、最小关心差异、统计单位和选择次数，再作资源估算。当前这些探索性区间不能充当注册依据之外的独立验证。
3. **选人方向：**先重新论证为什么所选几何目标应改善目标人群，使用训练/开发侧确定指标；当前外测已被查看，不可根据其结果重新选择人群后宣称确认。只重复同一 C 策略并加大训练量的价值低。
4. **240次成对角色互换：**保留为延期草案。若恢复，理由应是相同报告录音/文本与耦合随机数框架下的精度或稳健性增量，不是首次排除静态人物难度；它仍同时替换整个训练人群。

跨语料不能直接当语言因果实验。SUBESCO 只有20名说话人，增加随机种子不会变成更多独立人物；训练/验证/测试人物数、每类支持和文本匹配要重新设计。同一旧数据上的更复杂分析或更多模型，也不能替代独立人群证据。

## 5. 租哪张卡、租多久

**当前最佳方案是暂不租卡：0 张、0 小时、增量 GPU 费用为0。** 上面已经完成的检查无需模型训练或重新推理。旧的240拟合预算已在三个入口明确标为延期，不能据此自动启动云实例。

若将来确认要执行原240拟合方案，可继续用**单张 RTX 5090**作已有实测基础的候选：旧流程 cfg3 每次拟合均值约34.16秒，240次训练流程代理约2.28小时；含准备和取回的旧计划为3–4小时、按4小时预算，并需新流程技术 pilot 修正。它不是本轮测出的新执行时长，也没有证据宣称5090在所有平台都最便宜。

2026-09-07已查到的AutoDL公开基价5090为¥2.93/小时、会员展示价¥2.78/小时，对应4小时¥11.72/¥11.12，另计存储等；实际账户机器报价和库存未核实。4090/3090时租更低，但本任务速度尚未实测，不能只按每小时价格判每个实验总成本。Runpod及各卡价、实测边界见[价格快照](../validation_reporting/revision/gpu_market.md)和[历史资源核查](../validation_reporting/revision/REVISION_AND_BUDGET.md)。新确认实验规模若改变，以上240次预算不能直接沿用。

## 6. 复核与可复现范围

本目录保存三组独立复算脚本、输入SHA、逐人或逐选择表及结果JSON。DUAL读取旧预测核对角色与分数；E2读取小型声纹缓存并重建旧几何（最大差2.22×10⁻¹⁶）；DIAG从CSV恢复整数正确数作精确分解。它们用于检验本回应的计算，**没有重验全部模型权重，也不是独立训练复现**。新推断均标为事后、未作新的统一多重校正；旧主检验保持原身份。

轻量预测证据包值得另做，但本轮没有发布新的 Release，也不能说脱离权重即可执行全部旧审计入口：现有完整审计调用权重完整性 gate。后续若提供无权重包，需另设明确范围的预测重放入口，区分“分数重算”与“模型训练/权重完整性验证”。这不影响此次已完成的CPU核查和暂不新增GPU的决定。
