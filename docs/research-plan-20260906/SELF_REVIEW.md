## 必须继续接受质疑的地方

1. **创新强度尚无保证。**E1 单独很可能只是诊断；E2 的贡献依赖严格对照和真实收益；TTS 增强已有先例。文献核查范围有限，不能声明首次。
2. **新容量与测量尚未证明。**旧数据规模足够是必要条件；固定新角色、八句供给、G 四句查询与参考隔离仍须清单核验。新 ASV 距离可靠性也未测。
3. **条件性统计限制仍存在。**多个训练实例共享人群；逐人 bootstrap 不能创造独立训练数据集。当前方案适合诚实的估计与稳健性分析，不能自动支持确认性因果/等效主张。
4. **E3 可能在质量门槛失败。**同音色六情绪、足量可区分设计音色、逐类产率都可能不够；多租 GPU 不会修复控制能力。跨折共用配方/阈值还需独立开发来源或逐折校准，当前一次小试预算不能覆盖后者。身份听评和失败长尾还可能显著增价。
5. **E3 主要比较待讨论。**目前 E−D 为主；若论文主张补覆盖，F−E 可能更适合在结果前升为主比较，其他臂作为必要背景对照。
6. **语言不适合仓促塞进当前论文。**三主库只有两种语言且来源混杂；真人双语成本主要是采集与标注，同人设计也仍受熟练度和标签可比性限制。
